# Interview Prep — Backend/Infra (Java, Spring Boot, Algorithms, System Design)

A hands-on study repo for backend/infrastructure interview prep — Java, Spring Boot, algorithms,
system design, and behavioral prep for senior backend/infra roles.

Not actively job-hunting right now (see [`STUDY-PLAN.md`](STUDY-PLAN.md) for the no-rush pacing
and phased plan) — this repo is the working set for steady skill-building in the meantime.

## Structure

```
├── STUDY-PLAN.md      # Paced weekly plan + phases (start here)
├── ROLE-RESEARCH.md   # NY senior backend/infra market reference (for later, not active search)
├── system-design/     # Distributed systems, multi-region, Kafka, AWS migration, resilience
├── behavioral/         # STAR method + story scaffolding tied to real experience
├── algorithms/        # Data structures & algorithm problems
├── java-core/         # Core Java concepts (OOP, collections, concurrency, etc.)
├── mock interviews/   # Timed practice problems
├── notes/             # Concept write-ups per topic
└── spring-boot/        # Spring Boot concepts and mini-projects
```

## Where to start
1. [`STUDY-PLAN.md`](STUDY-PLAN.md) — the plan and pacing.
2. [`system-design/README.md`](system-design/README.md) — read through once for vocabulary and
   framing, especially the sections that map to your actual multi-region/Kafka/AWS/game-day work.
3. [`behavioral/my-stories.md`](behavioral/my-stories.md) — fill in your real stories using the
   prompts; this feeds both behavioral rounds and the "have you done this" system design follow-ups.
4. Keep chipping away at `algorithms/` and `mock interviews/` on a steady cadence.
